## 一、套利核心原理

跳蚤市场套利一共有 **三种模式**：

| 模式 | 公式 | 风险 | 回报 |
|:----:|:----|:----:|:----:|
| **🔄 商人→跳蚤** | 从商人低价买入 → 跳蚤高价卖出 | ⭐ | 🔥🔥🔥 |
| **🏭 藏身处制作** | 购买原料 → 制作 → 跳蚤卖出成品 | ⭐⭐ | 🔥🔥🔥🔥 |
| **🔄 跳蚤→商人** | 跳蚤低价买入 → 高价卖给商人 | ⭐⭐⭐ | 🔥🔥 |
| **📦 以物易物** | 用低价物品换高价物品 → 卖出 | ⭐⭐ | 🔥🔥🔥🔥🔥 |

## 二、高回报套利方案

### 🥇 Tier 1 — 稳定月常套利（验证过多个 wipe）

这些方案的利润经过多个版本验证，虽然不是每时每刻都暴利，但**整体稳定**。

#### 1. 灰头套（Shemagh）→  Therapist 套利

- **购入**：跳蚤市场低价扫灰头套
- **卖出**：Therapist LL2 回收价
- **原理**：灰头套在跳蚤供大于求时价格被压低，但 Therapist 回收价固定
- **利润率**：约 **5-15%**
- **适合**：没事扫一眼就赚

#### 2. 军用电缆（Military Cable）→ 跳蚤

- **购入**：Ragman LL3/L4 用杂物交换
- **跳蚤卖出**：需求量大（用于 藏身处升级 + 任务）
- **利润率**：约 **20-40%**
- **适合**：中期稳定收入

#### 3. 🔧 滤水器（Water Filter）→ 跳蚤

- **购入**：Jaeger LL3（~35k ₽）
- **跳蚤卖出**：通常 45-60k ₽
- **利润率**：约 **30-70%**
- **注意**：Wipe 初期价格更高，后期回落

#### 4. 🩸 CMS 手术包 → 跳蚤

- **购入**：Therapist LL3（~17k ₽）
- **跳蚤卖出**：约 25-35k ₽
- **利润率**：约 **50-100%**
- **适合**：任何时期，绷带类消耗品需求稳定

#### 5. 🔫 弹药反转套利

某些弹药在商人处卖得便宜，但在跳蚤上供不应求：

| 弹药 | 商人购入价 | 跳蚤卖出价 | 利润率 |
|:----:|:----------:|:----------:|:------:|
| M80 | Peacekeeper ~$3 | ~500-600 ₽ | **30-50%** |
| M62 | Peacekeeper ~$5 | ~800-1000 ₽ | **50-80%** |
| SS190 | Peacekeeper ~$4 | ~500-700 ₽ | **30-60%** |
| 7N31 | Prapor LL4 ~250 ₽ | ~500-800 ₽ | **100-220%** |
| AP 6.3 | Peacekeeper ~$3 | ~400-600 ₽ | **80-150%** |

> 📡 实时价格需以跳蚤市场为准

### 🥈 Tier 2 — 藏身处制作套利（被动收入）

藏身处制作是 **最稳定的被动收入来源**，只要你勤快收工。

#### 1. 🧊 比特币矿机（Bitcoin Farm）

| 项目 | 数值 |
|:----|:----:|
| GPU 成本 | 单卡 ~200-250k ₽ |
| 挖矿周期 | 1 GPU ≈ 25h/个，满配 ≈ 6-8h/个 |
| BTC 售价 | ~250-400k ₽（随游戏内 BTC 汇率浮动） |
| ROI 周期 | GPU 约 15-25 天回本 |
| **推荐** | 显卡>服务器>风扇；三级矿机+50卡才是完全体 |

> ⚠️ SPT 中无实时 BTC 价格，但可配置。

#### 2. 🪣 净水器（Water Collector）→ 超级滤水器

```
投入：
  滤水器 ×1    →  跳蚤 ~40k
  火力值 ×120h
━━━━━━━━━━━━━━━━━━━━━━
产出：
  超级滤水器 ×1  →  跳蚤 ~100-150k
━━━━━━━━━━━━━━━━━━━━━━
利润：~60-110k / 单次（5天周期）
利润率：150-275%
```

> ✅ 这是全游戏最稳的藏身处套利之一，几乎每个 wipe 都成立

#### 3. 🧪 火药（Gunpowder）→ 弹药制作

```
投入：
  绿茶 ×2       →  跳蚤 ~20k
  军用火药 ×1   →  跳蚤 ~30k
━━━━━━━━━━━━━━━━━━━━━━
产出：
  M80 × 120发   →  跳蚤 ~90-120k
  M61 × 100发   →  跳蚤 ~150-200k
━━━━━━━━━━━━━━━━━━━━━━
```

## 三、套利实战流程

### ⏰ 市场节奏

```
Wipe 第 1-7 天: 
  → 任何消耗品都赚钱（止血剂、绷带、廉价弹药）
  → 优先做 Ragman 背包 Barter
  
Wipe 第 2-4 周:
  → Filter + 超级滤水器套利进入黄金期
  → 弹药套利利润开始走高
  
Wipe 第 5 周+:
  → 比特币矿机 + 藏身处制作成为主流
  → 跳蚤市场趋于稳定，套利空间收窄，但仍可做
```

### 🧮 税费计算

跳蚤卖出并不等于你全拿，要记住：

```
实际到手 = 标价 × (1 - 手续费%)

手续费 ≈ 标价 × (RagFairCommissionModifier + 0.05)
其中 RagFairCommissionModifier 来自物品 tpl 属性
普通物品: 约 10-15%
高价值/稀有: 可能 15-20%
```

> 💡 **低于 5-10% 利润率的套利不要做**，扣完手续费可能就是亏

### 🛡️ FIR 标记

部分套利要求物品带 **FIR（Find In Raid）** 标记才能上跳蚤：
- 从商人直接买的物品 **不能上跳蚤**
- 所以 **商人→跳蚤** 套利只适用于：
  - 可以**在藏身处加工后再卖出**的物品（制作消除限制）
  - 直接卖给其他玩家需要通过**以物易物交易**而非跳蚤
  
> **要点**：商人购入价物品→藏身处制作→产出品可以上跳蚤（有 FIR 标记）

## 五、风险警告 ⚠️

1. **版本更新风险**：BSG 每次大更新都会调整商人价格和 Barter 配方
2. **跳蚤限制**：某些物品可能在更新后被加入/移出跳蚤白名单
3. **价格波动**：套利空间可能在几小时内消失（大量人跟风做）
4. **SPT 差异**：在离线版 SPT 中，跳蚤市场的价格由服务器配置决定，与在线版不同
5. **API 配置**：SPT 的跳蚤价格可在 `Server/configs/ragfair.json` 中调整
