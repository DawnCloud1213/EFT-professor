## 💡 用法

```bash
# 查看正利润排行（默认）
python scripts/craft_profits.py

# 按利润金额排序
python scripts/craft_profits.py --sort-profit

# 只看某设施
python scripts/craft_profits.py --station=Medstation

# 只看利润 > 1万卢布的
python scripts/craft_profits.py --min-profit=10000

# 强制从 API 拉取最新数据
python scripts/craft_profits.py --no-cache

# 查看所有配方（包括亏钱的）
python scripts/craft_profits.py --all
```
